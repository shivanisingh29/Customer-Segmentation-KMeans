## Customer Segmentation using KMeans Clustering
# Project Overview
   This project segments mall customers into groups based on their Annual Income and Spending Score using the KMeans Clustering algorithm. It helps businesses identify different types of customers and target them effectively.

## Technologies Used
- Python
- Scikit-learn
- Pandas
- Matplotlib
- Jupyter Notebook / PyCharm
- Dataset from kaggle.com(Dataset: Mall_Customers.csv) 

##Features used:
- Annual Income (k$)
- Spending Score (1-100)

## What I Did
Loaded Mall Customers dataset using Pandas
Selected key features — Annual Income and Spending Score
Applied KMeans Clustering with 3 clusters
Visualized customer segments using Scatter Plot
Output
Customers divided into 3 distinct segments
Scatter plot showing cluster distribution based on Income vs Spending Score
